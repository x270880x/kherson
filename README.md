# kherson

Интерактивная кадастровая карта Херсонской области.

Одностраничник на Leaflet (+ бета на MapLibre GL, `map-beta.html`), без бэкенда: 326 сельсоветов, 613 471 участок, векторные тайлы всех форм собственности, поиск по кадастру/владельцу/адресу, экспорт в Excel/CSV.

Сайт: https://x270880x.github.io/kherson/ (индексация закрыта — `robots.txt`/`noindex`)

Контекст для работы над проектом — в `ONBOARDING.md` и `CHANGELOG.md`.
